# TRADEPAL impact analysis

Before every meaningful addition/removal/modification, assess architecture, logic, calculations, state, flow, trading, visualization, inputs, compatibility, performance, complexity, maintainability, and unintended effects. Record PATCH, REFACTOR, or REBUILD in the proposed contract. Ask whether a fresh design with the new requirement would still choose the existing architecture.
