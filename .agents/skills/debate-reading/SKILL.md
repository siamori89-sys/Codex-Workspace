# DEBATE READING

Perform only faithful intake. Preserve wording, negations, conditions, examples, references, and logical relationships. Detect ALL-CAPS DEBATE components, `START DEBATE`, `STOP DEBATE`, one-turn level commands, and persistent level commands. Divide material only for routing; do not evaluate, infer, search, recall, analyze, reason, or reply substantively.
