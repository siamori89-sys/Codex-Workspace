# DEBATE REPLYING

For substantive turns, use compact sections when useful: **Answer**, **BRAIN ↔ MEMO**, and **Basis / References**. State conclusions, evidence, assumptions, objections, and resolution—not hidden reasoning traces. Cite searched sources and independent-source count when applicable. Cite memory IDs when relevant. Give a calibrated 0–10 confidence score. Do not invent sources, quotations, records, or certainty.
