# TRADEPAL versioning

Use Git as exact source history and `tradepal/state/version-ledger.md` for meaning. Update `current-version.md` for each meaningful version. Include chronology, changes/reason, behavior/features/techniques/architecture, PATCH/REFACTOR/REBUILD, strengths/weaknesses, validation, feedback, and why the next version is needed. Recover old source through Git, not vague memory.
